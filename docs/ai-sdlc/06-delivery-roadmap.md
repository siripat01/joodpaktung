# Delivery Roadmap

## Week 1 — Correct payment core foundation

Build the schema migrations, immutable ledger primitives, pure state machine, injectable clock, idempotency transaction wrapper, and unit tests.

**Done:** all legal/illegal transitions and ledger posting tests pass; every money-affecting path is atomic in PostgreSQL.

## Week 2 — Workers and integration proof

Build the Go timer/outbox worker, Mock Courier, HMAC verification, outbox/timer leases, reconciliation, and integration tests with real PostgreSQL.

**Done:** duplicate webhook, invalid transition, worker restart, timer claim, and reconciliation tests pass.

## Week 3 — Chaos and property proof

Build the deterministic scenario runner, failpoints, fast-check stateful model, quick/full test modes, replay reporting, and performance baseline for Go worker.

**Done:** all mandatory chaos scenarios pass; Quick Proof is under 60 seconds; Full Proof runs in CI.

## Week 4 — Demo UI and rehearsal

Build the three-panel Thai UI, SSE projections, state diagram, T-account display, test progress, reset flow, and recorded fallback demo.

**Done:** the full four-minute script runs without manual refresh; reset takes under two seconds; a recorded fallback is verified offline.

## Sequencing rule

Do not start interactive UI work until Week 1 payment-core tests are green. Console visualization may be built only after its data is generated by the real core and workers.
